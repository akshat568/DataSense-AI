# DataSense AI

An AI-powered Dataset Intelligence Platform that helps data scientists analyze datasets, identify data quality issues, recommend preprocessing pipelines, suggest machine learning algorithms, train baseline models, and explain predictions using Explainable AI.

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- Recharts

### Backend
- FastAPI
- Python

### Machine Learning
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- LightGBM
- CatBoost
- SHAP
